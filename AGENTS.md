# Agent guidance

## Project overview

This repository is a small Go HTTP application generated by Autostrada. It embeds HTML templates and static assets into the web binary, serves a home page and static files, and uses standard-library HTTP routing with structured logging.

## Task routing

| When the task involves… | Read first | Key rules |
|---|---|---|
| Web startup, configuration, or graceful shutdown | `cmd/web/main.go`, `cmd/web/server.go`, `internal/env/` | Configuration is read from environment variables; preserve flag behavior, timeouts, structured logging, and graceful shutdown. |
| HTTP routes, handlers, middleware, and errors | `cmd/web/routes.go`, `cmd/web/handlers.go`, `cmd/web/middleware.go`, `cmd/web/errors.go` | Keep handlers as methods on `application`; preserve route methods, security headers, recovery, request logging, and explicit error responses. |
| HTML pages, templates, or static assets | `assets/templates/`, `assets/static/`, `assets/efs.go`, `internal/response/` | Templates use `html/template` and are embedded at build time; use existing response helpers and escape untrusted values. |
| Request decoding and validation | `internal/request/`, `internal/validator/` | Reuse the existing decoding and validation helpers instead of duplicating parsing behavior. |
| Template helpers and shared response behavior | `internal/funcs/`, `internal/response/` | Preserve the established helper names and response status/header conventions. |
| Tests and quality checks | `Makefile`, package-local `*_test.go` files | Run `make test` and `make build`; use `make audit` when changing broad or security-sensitive behavior. |
| Pipeline or process configuration | `.ai/agentic.config.json`, `SDLC.md`, `.ai/trackers/`, `.ai/browsers/` | Keep config, descriptors, and process documentation synchronized; do not store credentials in repository files. |

## Validation

Run `make test` followed by `make build`. See `SDLC.md`, `CODE_REVIEW.md`, `BACKWARD_COMPATIBILITY.md`, and `.ai/agentic.config.json` for the delivery contract.
